# samples — 公式サンプル

README の聴き比べに使うサンプルの置き場。方針は `docs/SPEC.md` §15 にある。

- `sample_set.json` — 公式サンプルの種別の計画（目的関数 × 媒体プロファイルの 11 種、処理前の定義、置き場、公開範囲）。音声はまだない
- `public/`（予定） — 試聴用の音声（MP3）、各種別の Mix Report、サンプルの目録。実装フェーズで、本体のコマンドから生成して置く

決まっていること:

- 処理前は、12 ステムの単純合算（処理なし）
- 試聴用の MP3 はマスターではない。ロスレスのマスターと入力ステムは、GitHub の Release 添付に置く
- フル尺のステムや原本は、git の履歴に入れない。`.gitignore` は音声ファイルを既定で除外し、`samples/public/` だけを例外にする
- `samples/public/` の音声を更新するのは、リリースの節目だけ（履歴を太らせないため）
- 公開の直前に、権利条件を一次資料で再確認する
