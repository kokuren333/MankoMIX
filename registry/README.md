# registry — モデルレジストリ（データ）

ステム分離などに使うモデルの公式カタログを置く。**モデルウェイト本体は置かない**（初回利用時に、ユーザーの環境へ公式配布元から取得する）。方針は `docs/SPEC.md` §12。

- `models.json` — 公式カタログ。一次資料（ライセンスファイル、モデルカード、作者の声明）でライセンスを確認し、取得元と sha256 を固定したエントリだけを `verified` にする。根拠が足りないものは `candidate` のまま、理由を `status_reason` に書く
- 取得したウェイトはユーザー環境の `<MANKOMIX_HOME>/models/<id>/` に置く（既定は `~/.mankomix`）。BYOW の登録は `<MANKOMIX_HOME>/byow.json` に保存し、プロジェクトには書かない（実装は `core/registry.py`）
- ライセンスメタデータのないエントリは無効
- コードのライセンスとウェイトのライセンスは別々に記録する
- 使用目的を縛るライセンスのウェイトは公式カタログに入れない。ユーザーが自分で取得して登録する口（BYOW）で扱い、その範囲のライセンス確認はユーザーの責任とする
