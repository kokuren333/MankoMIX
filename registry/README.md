# registry — モデルレジストリ（データ）

ステム分離などに使うモデルの公式カタログを置く。**モデルウェイト本体は置かない**（初回利用時に、ユーザーの環境へ公式配布元から取得する）。方針は `docs/SPEC.md` §12。

- `models.json` — 公式カタログの候補（草案）。各エントリは、一次資料でライセンスを再確認し、取得元とハッシュを固定するまで `candidate` のまま
- ライセンスメタデータのないエントリは無効
- コードのライセンスとウェイトのライセンスは別々に記録する
- 使用目的を縛るライセンスのウェイトは公式カタログに入れない。ユーザーが自分で取得して登録する口（BYOW）で扱い、その範囲のライセンス確認はユーザーの責任とする
