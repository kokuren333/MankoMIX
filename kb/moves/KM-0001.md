# KM-0001 ドラムのピーク制御（S-08 対策）

## 主張

マスター計画が S-08（シマー）で差し戻されたとき、整音の強化ではなく、ミックス段の `trk_drums` にピーク検出のコンプレッサー（閾値 −15 dB、4:1、ニー 3 dB、アタック 1 ms、リリース 60 ms）を足すとリミッターの駆動が減り、S-08 が +1.51 → +1.12 dB に下がって合格した。

## 手（契約の形）

`chain_add`、target `trk_drums`、processor `compressor`、params `{ detector: peak, threshold_db: -15, ratio: 4, knee_db: 3, attack_ms: 1, release_ms: 60 }`

## 根拠

[v09 の乾式 7 案比較と描画後の実測](../songs/manko-shugi/retro_v09_club-s08/outcome.md)。−12 dB は余裕 0.03 dB と薄い。−18 dB はさらに下がるがアタックの丸まりが増える（推定）。

## 注意

- 聴感の確認が未了。アタック感がわずかに丸まる可能性
- 適用条件: リミッターの駆動が大きい出口（club 等）。streaming_universal（−14 LUFS）では S-08 が支配しない場合がある
