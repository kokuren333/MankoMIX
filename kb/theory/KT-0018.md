# KT-0018 参照は作品とクレジットで集める

## 要点

音の目標を集めるとき、パラメータの値を一つずつ集めるより、「この作品」「この技術者が関わった作品群」という単位で集める方が、実務の感覚に近く、伝わりやすい。
作品には編成・ジャンル・媒体の文脈が一緒に付いてくるため、数値だけでは見えない判断の理由が残る。
クレジットで束ねると、複数の作品に共通する傾向を一人の手の傾向として捉えられる。

## 指揮での使いどころ

- kb の work カード（作品）と engineer カード（クレジットされた技術者）を ID で指し、依頼の言葉の「この作品風」「この人の音」から引けるようにする設計の背景
- engineer カードの集計は傾向の目安で、個々の作品の読みを置き換えない
- 第三者作品の測定とカードは、既定で非公開の kb（`_private/kb/`）に置く

## 効かない条件・誤用

- 作品が一つしかなければ傾向とは呼べない
- 技術者の音は作品ごとの依頼や素材に左右され、一人の固定した様式とは限らない。人物評は書かない
