# KT-0004 音名と周波数

## 要点

平均律では半音ごとに周波数が一定の比（約 1.06 倍）で上がり、一オクターブで二倍になる。
基準の音の周波数（A を 440 Hz とすることが多い）から、すべての音名の周波数が決まる。
低い音域では一オクターブが数十 Hz に収まり、半音の差は数 Hz しかない。
キックやベースの基音、部屋や再生系の共振を、Hz の値と音名の両方で捉えられる。

## 指揮での使いどころ

- 低域の EQ の中心やハイパスの位置を、主音や根音の基音との関係で決める（R-07、R-16）
- キックの胴鳴りとベースの基音が同じ音名の近くにあるなら、どちらに低域を任せるかの割り当て問題として扱う（R-08）
- `direction query` の `band_energy` や `band_ratio` で主音の基音を含む帯を区間ごとに測ると、低域の量が進行につれて揺れる理由を説明できる

## 効かない条件・誤用

- 基準の音がずれた素材（生成物で起こりうる）では対応がずれる。解析の調律の推定を確かめる
- 倍音の多い音では、聞こえる高さと最もエネルギーの大きい周波数が一致しない（KT-0005）
- 帯域の数値は目安の幅であり、点ではない
