# 分析メモ p6 — マンコ主義 × 「ボーカルの言葉を前に」

凡例: 〔測定〕= 曲資料の値、〔測定・追加〕= 床のマスターへの `direction query` の値、〔推定〕= director の読み。

進め方: 小さな依頼なので型を縮めた。読んだのは曲資料 v2（§4、§9、§11）と床のマスターへの追加観察 1 回、規範データ（`knowledge/vocabulary.json`、`knowledge/mix_rules.json`）。省いたもの: 2b（リファレンス無し）、2a（kb カード・理論の棚・文献は引いていない）。

## 1 この曲の測定

- 声は既に大きい: P-10 5.77 で目標 [2, 5] の外に浮いている（未解決 `p10_off_target`）。対主役マスキングは 0.684 dB で良好〔測定 §4.3, §5.1〕。**「前に出ない」理由は音量でも埋もれでもない。**
- 声の素材は暗い: P-07 の帯域比は bass 0.45／lowmid 0.40／mid 0.14／highmid 0.07／air 0.01〔測定 §4.1〕。子音の帯（2–6 kHz）が薄い。
- 床の声のチェーン〔測定 §9〕: 3517 Hz の共鳴カット -3 dB（幅 0.33 oct）、ピーク検出コンプ（アタック 2 ms、4:1）、ディエッサー 6.5 kHz、サチュレーター、プレートへのセンド -18 dB。アタック 2 ms のピークコンプは子音の立ち上がりを先に抑える〔推定〕。
- 床のマスターの highmid 比（2–6 kHz／全帯域）: 全体 -14.47 dB、verse1（sec2）-17.15 dB。mid 比（500–2000 Hz）は sec2 で -11.30 dB〔測定・追加〕。声が主導する verse のほうが 2–6 kHz は薄い。
- 2–6 kHz を持つ他の素材は drums と percussion だけで、和声の楽器はこの帯にほとんど居ない〔測定 §4.1〕。競合を下げる手（R-05）は snare・hat を鈍らせるので取りにくい。

## 2 解釈と方針

- 「言葉を前に」= 子音の明瞭さと近さ〔確信度 medium〕。`mae_oku`（前後感は音量だけでなく帯域・トランジェント・残響で決まる）と `nukenai`（声を上げるのではなく帯域で解く）の語彙に沿う。「もう少し」= 小さな量。
- 手は声だけに 3 つ: (a) ピークコンプのアタックを 2 → 4〜8 ms（子音の立ち上がりを通す）、(b) 2.8 kHz を中心に広い +1.0〜+2.5 dB（R-06 の ±3 dB 内。床の 3.5 kHz の狭い共鳴カットは残す）、(c) プレートへのセンドを -18 → -22〜-20 dB（乾いたものは手前）。
- 触らない所: 声のフェーダー（P-10 を更に浮かせない）、ディエッサー、伴奏、パン、マスター。
- 壁: サ行（6–10 kHz）が増えうる（EQ の裾とアタックの緩み）。S-08 のシマー余裕 1.28 dB〔測定 §6.2〕。K 特性は 2–6 kHz を重く数えるので、レベルマッチ後は全体が少し下がる〔推定〕。主張は帯域比（レベルに依らない）で立てる。
- P-10・P-02 系は check で測り直されない（p1〜p3 の outcome）。「音量で前に出したのではない」ことは verse の mid 比が動かないことで機械表現する。

## 3 人への確認

「前に」は音量の意味か、言葉の聞き取りの意味か。仮定: 聞き取り（声は既に目標より大きい）。
