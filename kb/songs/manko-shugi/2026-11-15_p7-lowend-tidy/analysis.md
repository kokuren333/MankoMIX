# 分析メモ p7 — マンコ主義 × 「すっきり、キックとベースの重なり、小さな再生の低音」

凡例: 〔測定〕= 曲資料の値、〔測定・追加〕= 床のマスターへの `direction query` の値、〔走査〕= `direction edit scan` の値、〔推定〕= director の読み、〔理論: KT-nnnn〕= 理論カード。

進め方: 型は「1 → 2a → 3」。読んだのは曲資料 v2（§3〜§5、§9、§11）、edit scan の要約表と 6 トラックの区間別の値、床のマスターへの追加観察 2 回（帯域を細かく割った区間別エネルギー、`view` つきのラウドネス）、束 `cur_low-end-basics` と理論カード 4 枚、規範データ（rules、mix_rules、vocabulary）、同じ曲の p2・p6 の結果。省いたもの: 2b（リファレンス無し）。輪郭つきの一時 refstudy は目録の要約だけを見て根拠に使っていない（参照作品の測定で、床の測定ではない。〔参照〕としても扱わない）。

## 1 この曲の測定

- 低音の配役〔測定 §5.2〕: フェーダー込みで drums は sub -31.8／bass -24.9 dB、bass は sub -49.0／bass -29.5 dB。最低域を持つのはキック（ドラムのステムの中）で、ベースは 60–250 Hz にほぼ全量（P-07 比 0.98、lowmid 0.03、それより上は 0.00〔測定 §4.1〕）。
- 床の自己診断〔測定 §5.3、§11.1〕: bass 帯域の主役数 3（vocals・drums・bass）で、提案は「譲る trk_bass」。未解決 `band_density` のまま。床にダッキングは無く、drums はチェーン無し〔測定 §9〕。
- 重なりの場所〔測定・追加〕: 帯域エネルギー（dB、30–50／50–70／70–100／100–150 Hz）
  - sec10（ベースも声も不在、ドラムだけ）: -80.3／-73.0／-70.9／-70.6。キックは 50–150 Hz に広く居る。
  - sec9（ベースが曲中で最大、声は小さい）: -73.2／-64.7／-63.7／-62.5。
  - sec6（ベース不在、ドラムが小さい）: 100 Hz より下は -92 dB 以下。
  - sec10 のドラムを sec9 のドラムのレベル差（+4.7 dB〔測定 §3〕）だけ持ち上げて sec9 から引くと、残り（主にベース）は 50–150 Hz の 3 帯域ともキックと同程度かそれ以上〔推定。ドラムの打ち方が両区間で同じという仮定つき。確信度 low〜medium〕。**キックとベースは同じ 50–150 Hz に、ほぼ同じ量で居る。帯域で住み分ける隙間は見えない。**
- 小さな再生〔測定・追加〕: 40–150 Hz は全帯域の -2.96 dB（エネルギーの約半分）。モノ＋150–6000 Hz の見方（`mono_band`）では積分ラウドネスが -14.01 → -16.79 LUFS（-2.78 LU）。区間別の落差は sec2 -3.68、sec7 -3.35、sec9 -2.63、低音の無い sec6 は -0.38 LU。落差はほぼ低音の量そのもの。
- 低音の上の倍音〔測定・追加〕: 150–400 Hz の 40–150 Hz に対する比は全体 -3.51 dB、sec9 -6.16 dB、ドラムだけの sec10 -6.08 dB。ベースが主導する区間ほど、低音を 150 Hz より上で支えるものが少ない。
- モノ〔測定 §6.1、追加〕: `mono` の見方でラウドネス -14.01 → -14.11（-0.10 LU）。S-04 の低域モノ損失 0.020 dB、bass の相関 0.984、drums 0.999。低域は既に中央。
- 編集の候補〔走査〕: 既定値で拒否 0 件。`edit_trim`（末尾）は全トラック候補 0。`edit_gate` の候補は、読んだ 6 トラックの全区間で区間内最大フレームが -81 dBFS 以下（bass -81.0〜-89.8、backing_vocals -82.0〜-94.6、woodwinds -88.1 以下）、活動レベル比 -60 dB 以下。除くエネルギーはトラック全体比で bass -75.5、backing_vocals -66.7、woodwinds -69.6 dB。

## 2 知見

- 〔理論: KT-0024〕の 3 つの問いに当てると、この曲のベースは「重心が基音の付近」の側（P-07 比 0.98）。小さな再生で消えやすい型〔推定〕。
- 〔理論: KT-0026〕尾の長い低音を別の低音と同時に鳴らすときの選択肢は、役を絞る／区間で入れ替える／片方を相手に合わせて下げる（`duck`）。キック単独のステムが無いので前の 2 つは取れない。
- 〔理論: KT-0012〕と R-04・R-28: 処理の前に静的バランス、重要度の低い側（bass 0.70 < drums 0.80）が譲る。
- 〔理論: KT-0005〕と vocabulary `futoi`: 小さな再生系では基音を足すより倍音の帯で輪郭を補う。逆側の弁は `sukasuka`（R-29）。
- 同じ曲の実績: p2 は大きな量の主張で 0/3、p6 は小さな量で 1/1。ミックス段の量（P-10、P-22、P-02 系）は check で測り直されない。主張は観察量で、小さく立てる。

## 3 解釈と方針

- 「キックとベースが重なって聞こえる」= 同じ帯に同じ量で居る〔測定・追加＋推定〕。帯域で分けられないので**時間で分ける**: キックの打点の間だけベースを浅く下げる（`duck`、キーは drums の 40–120 Hz、回復は音価）。静的にも少しだけベースが譲る。
- 「小さな再生で低音の輪郭」= 2 つに分ける。(a) 低音の量が全体の半分を占めるので、レベルを揃えた小さな再生では残りが小さくなる → 重なった低音を減らせば落差が縮む（`view: mono_band` で主張できる）。(b) ベースの輪郭そのもの → ベースに倍音を足す。ただしマスターの 150–400 Hz は声と和声楽器が支配し、ベースの倍音はマスターの観察量にほぼ現れない〔推定〕。(b) は耳で確かめる手として書き、主張にしない。
- 「全体をもう少しすっきり」= 量は小さく。編集で「曲でない部分」を消す。候補区間は 3 つの独立な値（絶対レベル -81 dBFS 以下、活動レベル比 -60 dB 以下、除くエネルギー -66 dB 以下）がそろって無音同然を示し、曲資料 §3 の在・不在とも合う。フレーズの間に残った書き出しの底だと読む〔推定、確信度 medium〕。ただし量から見て、聞こえる差もマスターの観察量の差も出ない見込み。実証できるのは機構（区間・拒否・台帳・戻せること）で、効き目ではない。
- 編集の対象は 3 本に絞る: bass（依頼の主語。無音の区間がコンプのメイクアップを通る）、backing_vocals と woodwinds（候補の合計が 51.6 s・71.4 s と長く、リバーブへ送られている）。brass・strings は素材全体が -54.6／-64.1 LUFS で、残る側が「曲」かどうかを測定からは言えないので触らない（人への確認）。
- 触らない所: drums（キックを含む。チェーン無しのまま）、声、パン・幅、マスター。
- 壁: 主張の量が小さい（見込み 0.2〜0.4 dB）。低域の土台を削りすぎないこと（40–150 Hz の下限をガードに置く）。クレストは打点の瞬間の位相で向きが決まらないので主張にしない。

## 4 人への確認

- 「すっきり」は低域の整理の意味か、楽器の数・残響まで含むか。仮定: 低域の整理と無音区間の掃除まで。
- brass・strings はほぼ無音の素材。曲の一部として残すか。仮定: 残す（触らない）。
