# KL-0001 同一収束

## 主張

目的関数（comfort／bass_heavy／club_impact）を変えても、ミックス計画の固定順の操作が同じ手を選び、音が同一になることがある。変種の差を約束する前に、床との同一収束を機械で確かめる。

## 根拠

[v01／v02 の実測](../songs/manko-shugi/retro_v01-v02_floor-convergence/outcome.md): 差はディザーだけ（差分 RMS −141.5 dBFS）。club の v09〜v11 も同一。キックのダッキングは床で 0.0017 dB しか効かず棄却。

## 使い方

- 指揮書の手は床に重ねる差分として書き、`direction check` で床との同一収束（ミックス changes のハッシュ、レベルマッチ後の差分 RMS）を確かめる
- 効かない定石（解く対象がない手）は持ち込まない（v2 J-6）
