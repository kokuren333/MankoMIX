# profiles — 媒体プロファイルと納品形式（データ）

- `media_profiles.json` — 媒体プロファイルの草案。出口の制約条件（再生側のラウドネス正規化、True Peak 天井、コーデック検査、再生環境の想定）
- `delivery_formats.json` — 納品形式の草案。ファイルの条件（サンプルレート、ビット深度、ディザ）

注意:

- ラウドネスの数値は納品規格ではなく、再生時の正規化レベルである。音作りの目標ではなく配送条件として扱う（`docs/SPEC.md` §5.1）
- 数値は調査時点のもので、公式に公表されている値は一部だけである。各プロファイルは公式度を持つ。実装時と公開時に再確認する
- レンジを持つプロファイル（`sns_hot`、`club`、`cd`）の既定値は確定済み（決定 D-046）。許容幅は初期値で、較正の対象
