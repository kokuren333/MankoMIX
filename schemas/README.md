# schemas — JSON Schema

正本とデータ定義の JSON Schema を置く。

| 予定ファイル | 対象 | 仕様 |
|---|---|---|
| `project.schema.json` | プロジェクトの正本 | `docs/SPEC.md` §9 |
| `objective.schema.json` | 目的関数の定義 | §4.8 |
| `media_profile.schema.json` / `delivery_format.schema.json` | 媒体プロファイル、納品形式 | §5 |
| `registry.schema.json` | モデルレジストリ | §12.2 |
| `report.schema.json` | Mix Report | §6.8 |
| `chain.schema.json` | プロセッサグラフ（プラグインとの共有契約） | §6.5.2、§14.2 |

現在は骨格のみ。スキーマは実装フェーズの最初のマイルストーン（M1）で確定する。
