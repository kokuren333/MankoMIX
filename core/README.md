予定している構成要素:

- プロジェクト管理（正本 JSON の読み書き、検証、操作履歴）— §9
- 入力アダプタ（v1 はファイル入力のみ）— §6.1
- 解析と測定（測定ベクトル P-01〜P-21）— §4.2、§6.3
- 目的関数の評価、媒体プロファイルの適用 — §4、§5
- プランナー（決定的。LLM を呼ばない）— §7
- 検証と Mix Report — §6.7、§6.8
- モデルレジストリ — §12
