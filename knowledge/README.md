# knowledge — 判断規則と知覚語彙（データ）

エージェントとプランナーが参照し、Mix Report が引用する知識を、コードでなくデータとして置く。

| 予定データ | 内容 | 仕様 |
|---|---|---|
| 判断規則の索引 | R-01〜R-27。規則、型、確立度、既定の閾値 | `docs/SPEC.md` §7.3 |
| 閾値と初期値 | 安全不変条件と警告の閾値（[慣行] の値は較正対象） | §4.3 |
| 帯域役割表 | 帯域 → 知覚的な役割（パワー、厚み、明瞭度、空気感など） | §8 |
| 知覚語彙辞書 | 語彙 → 指す現象と帯域 → 典型的な対処。Mix Report の説明語彙 | §6.8 |

確立度のラベル（[規格] / [モデル] / [慣行]）を各項目に持たせ、不変条件と実務慣行を混ぜない（§0.1）。

現在は骨格のみ。知覚語彙辞書の本体は、調査資料の再受領後に整備する。
