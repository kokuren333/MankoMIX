# knowledge — 判断規則と知覚語彙（データ）

エージェントとプランナーが参照し、Mix Report が引用する知識を、コードでなくデータとして置く。

| データ | 内容 | 仕様 | 状態 |
|---|---|---|---|
| `genre_priors.json` | ジャンル prior（低域の主導役、主役帯域レベル差の目標帯、重くする指標）と、ステム重要度の既定順 | `docs/SPEC.md` §4.10、§4.11 | 草案 |
| `objective_metrics.json` | 目的関数の項の目標範囲・ペナルティの尺度・強度の上限、リファレンス分布の既定幅、トランスレーション・ゲートとプランナーの初期値 | §4.1、§4.5〜§4.7、§7.2 | 草案 |
| `vocabulary.json` | 帯域とイメージの早見表、知覚語彙辞書（語彙 → 現象と帯域 → 代理指標 → 対処 → 逆向きの安全弁） | §6.8.1 | 草案 |
| `rules.json` | 判断規則の索引 R-01〜R-33（規則の文言 ja/en、型、関係する代理指標 P-nn と不変条件 S-nn）。`knowledge_lookup` で引ける | §7.3 | 草案 |
| 閾値と初期値 | 安全不変条件と警告の閾値（[慣行] の値は較正対象） | §4.3 | 予定 |
| 入力パターン | 書き出しセットのファイル名パターンと役割の対応表（Suno Studio のマルチトラック書き出しなど） | §6.1.3 | 予定 |

守ること:

- 確立度のラベル（[規格] / [モデル] / [慣行]）を各項目に持たせ、不変条件と実務慣行を混ぜない（§0.1）
- ジャンル prior は重みと目標範囲の初期値にだけ使う。リファレンスの実測とユーザーの指定が常に優先する
- 語彙は印象のラベルであって、目的関数の名前でも評価の軸でもない。説明では必ず測定値と対にする
- 帯域の数値は目安の幅であり、較正の対象である
