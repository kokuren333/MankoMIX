# spec/08 ピッチ／タイム（14 件）

カタログ §8。共通規約は `spec/01_dynamics.md` §0。タグは 2 代目 PM が付けた。**Rubber Band（GPL）・SoundTouch（LGPL）・aubio（GPL）・PaulStretch 原実装（GPL）は読まない・使わない。**

## 0. カテゴリ共通

### 0.1 表面の分け方（本カテゴリ以降の規則。PM_PLAN BB-18）

| 性質 | 表面 |
|---|---|
| 1 入力・出力が同じ長さ・曲頭から順に計算できる | チェーンのプロセッサ |
| 同じ長さだが曲全体の解析が先に要る（音程の追跡など） | プロセッサ、`offline_only: True` |
| **長さが変わる／別のトラックの音が要る／素材の区間を指定して作り替える** | **編集段の op（`edit_*`）が「派生クリップ」を作る**（BB-18） |

派生クリップ（BB-18）の規則：

- 元素材は書き換えない。op は「元のクリップ（素材の sha256、区間）＋ op のパラメータ＋処理コードの版」から派生音声を計算し、内容ハッシュを鍵に局所キャッシュへ置き、台帳には元と op の記録だけを書く。キャッシュが無ければ同じ結果を作り直せる（作り直した sha256 が台帳の値と違えば明示エラー）
- **プロジェクトの尺は変えない。** 伸縮でクリップが伸びた分は、クリップの `fit`（`keep_start`＝頭を固定して尾が伸びる／`keep_length`＝元の区間長で切る・足りない分は無音）で決める。他クリップと重なったら拒否（既存の編集段と同じ規則に従う。実働が `DIRECTION_FORMAT` §7.1 を読んで合わせる）
- 派生クリップ op は `stage: edit`。適用記録に「元の尺・後の尺・前後の測定（積分ラウドネス、ピーク）」を残す
- S-09（尺とサンプル位置の保存、ステム間の時間整合）との関係は PM_PLAN OD-11。**既定：検証の定義は変えない。**

### 0.2 ピッチ・タイムの核（BB-11。品質等級を宣言する）

| 等級 | 方式 | 向き | レイテンシ |
|---|---|---|---|
| `fast` | (a) 遅延線 2 タップ交差 | 小さなずれ、帰還ループ内、効果 | 0（乾側の補償なし） |
| `standard` | (b) WSOLA（波形の類似で継ぎ目を合わせる）＋リサンプル | 単音・声・打楽器 | 窓長 |
| `high` | (c) 位相ロック付き位相ボコーダ＋過渡の扱い（過渡フレームで位相をリセット） | 和音・ミックス | 窓長（4096 @48k） |

- フォルマント保存（BB-19）：スペクトル包絡（ケプストラムの低ケフレンシ、または LPC）を推定し、ずらす前の包絡へ掛け戻す。`standard` では TD-PSOLA（ピッチ同期の重ね合わせ）が有声音の正
- 音程の追跡（BB-12）：pYIN。固定格子（ホップ 256 @48k 相当。sr に比例）。追跡が要る型は `offline_only: True`
- **効き目の主張は測定上の到達まで**（W3 のゲートと同じ）。「自然に聞こえる」とは書かない

**共通テスト（PT）**：(PT1) ずれ 0・比 1 で、遅延補償後のヌル：`fast` ≤ −80、`standard` ≤ −60、`high` ≤ −80 dBFS（各件で中立を経路迂回にしてビット一致にできる型はそうする） (PT2) 正弦の周波数が目標 ±3 セント（`fast` は ±10） (PT3) 定常正弦で包絡のリップル：`fast` ≤ 1 dB、`standard` ≤ 0.5 dB、`high` ≤ 0.2 dB (PT4) 出力の尺：同じ長さの型は入力と同じサンプル数。伸縮は round(入力長×比) ±1 サンプル (PT5) 過渡：クリック列（100 ms 間隔）を伸縮・シフトして、各クリックの時間的な広がり（エネルギーの 90 % が入る幅）が `standard` ≤ 5 ms、`high` ≤ 10 ms、位置ずれ ≤ 5 ms (PT6) フォルマント保存：合成母音（固定のフォルマント 3 本＋基音）を +5 半音して、スペクトル包絡の山の周波数のずれ ≤ 3 %（保存あり）、保存なしでは比例して動く

カテゴリの正典（最初に読む）：Driedger & Müller「A Review of Time-Scale Modification of Music Signals」Applied Sciences 2016（オープンアクセスの総説。WSOLA・位相ボコーダ・調波打楽分離の併用まで）／Laroche & Dolson「Improved Phase Vocoder Time-Scale Modification of Audio」IEEE Trans. SAP 1999（位相ロック）／Verhelst & Roelands「An Overlap-Add Technique Based on Waveform Similarity (WSOLA)」ICASSP 1993／Moulines & Charpentier「Pitch-Synchronous Waveform Processing Techniques for Text-to-Speech Synthesis Using Diphones」Speech Communication 1990（PSOLA）／Mauch & Dixon「pYIN」ICASSP 2014／Röbel & Rodet「Efficient Spectral Envelope Estimation and its Application to Pitch Shifting and Envelope Preservation」DAFx-05

## T08-01 自動ピッチ補正

`pitch_correct`｜B（PM 判断：カタログは「品質はモデルと検出精度に依存」と書くが、古典的な検出＋PSOLA は決定論で書ける。学習モデルは使わない）｜W3｜L｜Codex｜TV｜`offline_only: True`｜`stages: ["track"]`

| id | 型 | 単位 | 範囲 | 既定 |
|---|---|---|---|---|
| `key` | e | — | `C`〜`B`（12 音） | `C` |
| `scale` | e | — | `chromatic`／`major`／`minor`／`custom` | `chromatic` |
| `scale_mask` | a | 0/1 | 長さ 12（`custom` のとき必須。`key` からの度数で 1＝使う音） | `[]` |
| `a4_hz` | f | Hz | 400〜480 | 440 |
| `retune_ms` | f | ms | 0〜500 | 80（目標へ寄る時定数。0＝即時＝階段状の効果） |
| `amount` | f | 0..1 | 0〜1 | 1（補正量。0＝ビット一致の素通し） |
| `tolerance_cents` | f | セント | 0〜50 | 0（これ以内のずれは触らない） |
| `keep_vibrato` | f | 0..1 | 0〜1 | 0.7（音符内の速い揺れ〈4〜8 Hz〉を補正から外す度合い） |
| `transition_ms` | f | ms | 0〜300 | 60（音符の変わり目で補正を弱める幅。しゃくり・滑りを残す） |
| `formant` | b | — | — | true（フォルマント保存） |
| `lo_hz`・`hi_hz` | f | Hz | 40〜400／200〜2000 | 70／1000（追跡の範囲） |
| `min_confidence` | f | 0..1 | 0〜1 | 0.6（有声の確からしさがこれ未満の区間は触らない） |
| `targets` | c | x：曲頭からの秒／y：MIDI 音高（小数可） | 最大 4096 点 | `[]`（書けば、その区間は音階でなくこの線へ寄せる。階段補間） |

- アルゴリズム：pYIN で基音の軌跡と有声確率 → 音符への区切り（半音量子化＋最短長 60 ms のヒステリシス）→ 音符ごとの目標（音階上の最寄り、同距離なら低い方）→ 補正曲線（セント）＝目標−実測を、`retune_ms` の 1 次遅れ・ビブラート除外・変わり目の緩和で整形 → TD-PSOLA（`formant=true`）か `standard` のシフタで適用。無声・低確信の区間は遅延だけで通す（その境目は 10 ms で交差）
- 正典：Mauch & Dixon 2014／Moulines & Charpentier 1990／de Cheveigné & Kawahara「YIN」JASA 2002。**Auto-Tune の特許・実装は読まない**（原理は上の公開文献で足りる）
- 記録：音符の一覧（開始・終了・実測の中央値・目標・補正量の最大）、触らなかった区間の割合、平均の有声確率
- テスト（PT に加えて）：(1) `amount=0` でビット一致 (2) 合成母音を音階から +30 セントずらしたもの：出力の音程の中央値が目標 ±5 セント、`retune_ms` の時定数 ±20 % (3) 5 Hz・±40 セントのビブラートつき：`keep_vibrato=1` で揺れの幅が 80 % 以上残り、中心だけ寄る／`0` で 30 % 以下 (4) 無声（雑音）区間・無音：遅延補償後ヌル ≤ −120 dBFS (5) `custom` の `scale_mask` で外した音へ寄らない (6) `targets` を書いた区間は線に ±5 セント (7) PT6 (8) 2 回描画一致（pYIN の出力が格子上で決定的）
- 弱点：和音・重なった声には使えない（単音前提）。追跡を誤った区間は誤った方向へ動かす（`min_confidence` で触らない側へ倒している）
- 依存：BB-00、BB-11、BB-12、BB-19

## T08-02 グラフィカル・ピッチ／タイミング編集

**下見コマンド `direction pitch notes`＋編集段の op `edit_pitch`＋GUI の音符表示**｜D｜W4（当てる側の `pitch_curve` は W3）｜L｜Codex
「音符単位の手作業編集環境」。指揮者（人・AI）が音符の一覧を読み、直したい音符だけを指揮書に書く。

`direction pitch notes`（読み取り専用）：`--project`、`--target trk_<stem>`、`--section`、`--lo-hz`・`--hi-hz`、`--a4`。出力（JSON）：音符ごとに `id`（区間から決まる安定な ID：`n_<開始サンプル>`）、`t0`・`t1`、`pitch_midi`（中央値）、`cents_off`（最寄りの半音から）、`drift_cents`（音符内の傾き）、`vibrato`（速さ Hz・幅セント）、`confidence`、`level_db`。**直すべきとは言わない**（一覧と当てになり度だけ）。

op `edit_pitch` の `params`：

| id | 単位 | 範囲 | 省略時 |
|---|---|---|---|
| `notes` | 配列（最大 256 個）。各要素は下の欄 | | （必須） |
| ├ `t0`・`t1` | 秒（クリップ内） | `t1`＞`t0`、互いに重ならない | （必須） |
| ├ `shift_cents` | セント | −1200〜1200 | 0（音符全体の平行移動） |
| ├ `flatten` | 0..1 | 0〜1 | 0（音符内の傾き・ふらつきを平らにする量） |
| ├ `vibrato` | 倍 | 0〜2 | 1（揺れの幅の倍率） |
| ├ `formant_cents` | セント | −600〜600 | 0（声質だけを動かす） |
| ├ `move_ms` | ms | −200〜200 | 0（音符の頭の時刻を動かす。隣の音符との間を伸縮で埋める） |
| ├ `gain_db` | dB | −12〜12 | 0 |
| `transition_ms` | ms | 0〜200 | 30 |
| `formant` | 真偽 | — | true |

- 展開：音符列 → 時間つきのセント曲線・フォルマント曲線・時間写像・ゲイン曲線 → 派生クリップ（BB-18。T08-14 `pitch_curve` と同じ核＋ BB-11b の可変伸縮）。`target` はトラック ID（クリップを持つもの）
- GUI（W4）：音符の帯と音程の線の表示、op を書いた音符の前後比較。**表示だけ。GUI にしか無い数値を作らない**（同じ一覧が CLI／MCP から出る）
- テスト：(1) `notes` コマンドが読み取り専用・再現一致 (2) 合成の旋律（音符 8 個、既知の音高・長さ）：検出した音符の境界 ±20 ms、音高 ±5 セント (3) `shift_cents=+100` の音符だけ +100 ±5 セント、他の音符は派生前とヌル ≤ −60 dBFS（変わり目の外） (4) `flatten=1`：音符内の音程の標準偏差が 20 % 以下に (5) `move_ms=+50`：その音符の頭が +50 ±5 ms、曲の尺とその後の音符の位置は不変 (6) 全項目 0 の `notes` は派生クリップを作らない（元と同一と記録） (7) `edit_pitch` を含まない指揮書はバイト同一（G0-4）
- 依存：BB-11、BB-12、BB-18、BB-19、T08-14

### 実装時の確定（統括の判断 D-28）

音符表示GUIはOQ-3で保留。`direction pitch notes`・`edit_pitch`・`pitch_curve` の数値指定を利用する。GUIバックエンドへのAPI追加はcore差分0と両立しないため、この判断ではcoreを変更しない。

## T08-04 ハーモナイザー

`harmonizer`｜A（BB-11 の組み立て）｜W3｜M｜Codex｜`stages: ["track","bus"]`

| id | 型 | 単位 | 範囲 | 既定 |
|---|---|---|---|---|

| `formant` | b | — | — | false（`standard`・`high` のときだけ効く） |
| `dry_db` | f | dB | −90〜6 | 0 |

- アルゴリズム：声部ごとに固定比のシフタ（BB-11）＋遅延＋帰還。音程の追跡をしない（平行移動）。`feedback>0` は `fast` のときだけ（ループ内に置けるのは遅延 0 の方式だけ。他の等級で書いたら拒否）
- テスト（PT に加えて）：(1) 全声部 −60 dB・`dry_db=0` でビット一致 (2) 440 Hz：声部の周波数が 440·2^(半音/12) ±PT2 (3) `feedback=0.5`・`delay_ms=250`：n 回目の反復が n 倍のずれ、レベルが −6n dB ±0.5 (4) `feedback=0.9` で有界（CT-8） (5) 声部数に依らず乾音がビット一致で通る
- 依存：BB-09、BB-11、BB-19

### 実装時の確定（統括の判断 D-13）

`harmonizer` の能動帰還は声部ごとに遅延＋grainと声部利得を含めて60秒減衰を交差検査する（W3b）。旧feedback0.9・delay1000 ms・grain200 ms・level−6 dBは末尾 −84.2904093520269 dBFSで未達、この条件の上限は0.7397269505182111。delay250/grain40/level−6の上限0.9251434100034163では0.9を許す。単項目の範囲・既定を変更しない。

| `cents` | f | セント | −100〜100 | 0 |
| `quality` | e | — | `fast`／`standard`／`high` | `high` |
| `formant` | b | — | — | false |
| `formant_cents` | f | セント | −1200〜1200 | 0（`formant=true` のとき、保存した包絡をさらに動かす） |

- 正典：カテゴリの正典／Röbel「A New Approach to Transient Processing in the Phase Vocoder」DAFx-03（過渡）／Driedger, Müller & Ewert「Improving Time-Scale Modification of Music Signals Using Harmonic-Percussive Separation」IEEE SPL 2014（併用する場合）
- テスト：PT1〜6 の全部が本型の合格条件（BB-11 の受け入れ試験を兼ねる）。加えて (1) ずれ 0 でビット一致 (2) ステレオ：左右同一の入力で左右同一の出力、広い素材で左右相関の変化 ≤ 0.05（`stereo_link`） (3) ±12 半音で 100 Hz〜8 kHz の対数掃引：瞬時周波数が目標 ±5 セント (4) 上向きでナイキストを超える成分の折り返し ≤ −70 dB (5) CT-5
- 依存：BB-06、BB-09、BB-11、BB-19

### 実装時の確定（統括の判断 D-13）

C8a で本型の standard はWSOLAから位相ボコーダ経路へ変更した。他型のstandardと共有部品の既定WSOLAは維持する。highのwindowは宣言バッファ長・フォルマント補正窓に保持し、追従解析窓は48 kHz基準2048を上限とする。fastの新解析経路は全文脈バッファ処理であり、宣言遅延0をゼロ先読みの保証とはしない。公開値・PT/CTの合格数値は不変。

`poly_retune`｜B｜W3｜L（調査レッグが先）｜**Opus 中**（方式の選択と妥協点の判断が重い）｜TV｜`offline_only: True`｜`stages: ["track","bus"]`

| id | 型 | 単位 | 範囲 | 既定 |
|---|---|---|---|---|
| `map` | a | 半音 | 長さ 12、各 −6〜6（音名 C〜B それぞれを何半音動かすか。全 0＝ビット一致の素通し） | 全 0 |
| `a4_hz` | f | Hz | 400〜480 | 440 |
| `strength` | f | 0..1 | 0〜1 | 1（0＝動かさない、1＝格子へ吸着したうえで動かす。間は元のずれを残す） |
| `window` | e | — | 4096／8192／16384 | 8192（48 kHz 基準） |
| `lo_hz`・`hi_hz` | f | Hz | 20〜500／1000〜20000 | 60／12000（動かす範囲。外は触らない） |
| `min_peak_db` | f | dB | −90〜−30 | −60（フレーム最大比。これより弱い山は動かさない） |
| `transients` | f | 0..1 | 0〜1 | 0.7（過渡フレームは動かさず通す度合い） |

- アルゴリズム：STFT → スペクトルの山（正弦成分）を拾う。山を 1 つずつ最寄りの音名へ割り当てると、倍音が基音と別の音名へ行って和音が壊れる。そこで**調波のまとまりを先に作る**：(1) 山の列から基音候補を多重基音推定（調波の和の重み）で拾い、山を基音へ所属させる (2) 所属した山はその基音の音名の `map` で**同じ比だけ**動かす (3) 所属の無い山は自分の周波数の音名で動かす (4) 山の周りの領域ごと周波数軸上で移し、位相を移動量に合わせて回す（Laroche & Dolson の「山の領域のシフト」）。過渡フレームは通す
- 正典：Laroche & Dolson「New Phase-Vocoder Techniques for Pitch-Shifting, Harmonizing and Other Exotic Effects」WASPAA 1999（山の領域のシフト。**これが核**）／Klapuri「Multiple Fundamental Frequency Estimation by Summing Harmonic Amplitudes」ISMIR 2006／McAulay & Quatieri「Speech Analysis/Synthesis Based on a Sinusoidal Representation」IEEE Trans. ASSP 1986。調査レッグ：多重基音推定の誤りが出力をどう壊すかを合成和音で先に確かめ、所属の閾値を決める。**Zynaptiq の製品・特許は読まない**
- テスト：(1) `map` 全 0 でビット一致 (2) 合成のハ長調の三和音（各音 6 倍音、ド・ミ・ソ）、`map` でミ→ミ♭（−1）：出力の成分がド・ミ♭・ソの調波列に ±10 セント、ド・ソの成分のレベル変化 ≤ 1 dB (3) 同じ和音で、ミの第 5 倍音（ソ♯付近）がミと一緒に −1 半音動く（所属の確認） (4) 範囲外・`min_peak_db` 未満の成分はヌル ≤ −60 dBFS (5) クリック列：PT5 の `high` の基準 (6) 2 回描画一致
- 弱点（**正直に**）：本カタログで最も効き目が怪しい件。倍音が重なる和音（オクターブ、5 度）は所属を一意に決められない。打楽器・雑音成分は濁る。測定基準を満たしても実用に耐えない可能性が高い。PM_PLAN §9
- 依存：BB-06、BB-11（c）、BB-12

## T08-08 ボコーダー

`vocoder`｜A｜W2（外部キャリアの op `vocode` は W4）｜M｜Codex｜TV｜`stages: ["track","bus"]`
**プロセッサは 1 入力。** 入力＝変調側（声）。搬送側は (a) 内蔵の発振器、(b) 別トラック、の 2 通り。(b) はプロセッサに 2 つ目の入力を足さず、op が包絡を先に測る（spec/01 T01-10 と同じ考え方）。

`vocoder`（内蔵キャリア）：

| id | 型 | 単位 | 範囲 | 既定 |
|---|---|---|---|---|
| `bands` | i | 本 | 4〜40 | 16 |
| `lo_hz`・`hi_hz` | f | Hz | 50〜500／2000〜16000 | 100／8000（帯域の配置は対数等間隔） |
| `carrier` | e | — | `saw`／`pulse`／`noise`／`saw_noise` | `saw_noise` |
| `notes` | a | MIDI 音高 | 0〜127、最大 8 個（和音） | `[48, 55, 60, 64]` |
| `notes_curve` | c | x：秒／y：MIDI 音高 | 最大 1024 点、階段補間 | `[]`（書けば単音で、`notes` の代わり） |
| `a4_hz` | f | Hz | 400〜480 | 440 |
| `attack_ms`・`release_ms` | f | ms | 0.5〜50／5〜500 | 5／40（帯域包絡の追従） |
| `formant_shift` | f | 半音 | −12〜12 | 0（分析帯域と合成帯域の対応をずらす） |
| `unvoiced` | f | 0..1 | 0〜1 | 0.5（高域の無声成分〈子音〉を雑音キャリア／原音の高域で補う量） |
| `band_q` | f | — | 2〜20 | 8 |
| `envelopes` | as | `derived` レジストリ（BB-18。種別 `control`） | ID または空 | 空（op `vocode` が書く。空＝自分の入力から測る） |
| `mix`・`output_db`・`seed` | | | | 1／0／0 |

- アルゴリズム：分析フィルタ群（4 次バンドパス）→ 包絡（整流＋平滑）→ 同じ配置の合成フィルタ群を通したキャリアに掛ける → 加算。発振器は帯域制限（PolyBLEP ではなく加算合成で 0.45×sr まで。位相は絶対時刻から）。雑音は PCG64
- op `vocode`（mix 段）：`target`＝搬送側のトラック、`params.key`＝変調側のトラック、ほか `bands`・`lo_hz`・`hi_hz`・`attack_ms`・`release_ms`・`formant_shift`・`depth`（0〜1）。展開：変調側の帯域包絡を測って派生資産（`control`：帯域×時間の配列、ホップ 5 ms）に置き、搬送側のチェーン末尾にプロセッサ `band_envelope`（`envelopes` の資産 ID、帯域配置）を足す。`band_envelope` は入力を同じフィルタ群に通し、資産の包絡を掛けて加算するだけ
- 正典：Dudley「The Vocoder」Bell Labs Record 1939（原理）／Zölzer 編『DAFX』（チャンネルボコーダ、相互合成）
- テスト：(1) `mix=0` でビット一致 (2) 変調側に帯域 k の中心の正弦：出力のエネルギーの 90 % 以上が合成帯域 k（`formant_shift` を掛ければ k＋ずれ） (3) 無音入力→無音 (4) 包絡の追従時定数 ±15 % (5) キャリアの倍音が `notes` の調波列上（±2 セント）、折り返し ≤ −70 dB (6) op：包絡の資産が再現一致、`vocode` を含まない指揮書はバイト同一 (7) op 経由と、同じ声を直接入れた `vocoder`（キャリアを同じ音に固定した試験用構成）の包絡が一致
- 依存：BB-00、BB-03、BB-05、BB-18（op）

## T08-09 トークボックス

`talkbox`｜B｜W3｜M（T08-08 の後）｜Codex｜TV｜`stages: ["track","bus"]`

`vocoder` と同じ入力の規約（入力＝声、キャリアは内蔵か op `vocode` の `mode=lpc`）。パラメータは `vocoder` の `carrier`・`notes`・`notes_curve`・`a4_hz`・`mix`・`output_db`・`seed` に加えて：`order`（i、8〜48、既定 24：LPC 次数。48 kHz 基準）、`frame_ms`（f、10〜40、20）、`tube`（f、0〜1、0.5：管と口の経路の色＝300 Hz〜4 kHz の帯域制限と共振）、`driver_db`（f、0〜24、6：駆動ユニットの飽和）、`emphasis`（f、0〜1、0.5：フォルマントの山を鋭くする量。極の半径を寄せる）、`unvoiced`（f、0〜1、0.3）。

- アルゴリズム：声を LPC 分析（自己相関法、Burg 法のどちらかに固定。フレーム間は反射係数で補間：安定性が保たれる）→ 全極フィルタでキャリアを通す（＝声道の形をキャリアに被せる）。帯域ボコーダより山が鋭い。前段でキャリアを飽和（`driver_db`）、後段で `tube` の帯域制限
- 正典：Makhoul 1975／Atal & Hanauer「Speech Analysis and Synthesis by Linear Prediction of the Speech Wave」JASA 1971／Zölzer 編『DAFX』（LPC による相互合成）
- テスト：(1) `mix=0` でビット一致 (2) 合成母音（フォルマント 3 本）を入力：出力の包絡の山が入力のフォルマント ±5 %、基音は `notes` (3) 全極フィルタが全フレームで安定（極の半径 < 1。性質テスト） (4) フレーム境界に同期した変調が無い（定常入力で包絡リップル ≤ 0.2 dB） (5) 無音→無音、出力有界
- 依存：BB-13、BB-19、T08-08

## T08-11 極端タイムストレッチ

**編集段の op `edit_stretch_extreme`（派生クリップ）**｜A（アルゴリズムは公開済み・単純）｜W4｜S｜Codex
