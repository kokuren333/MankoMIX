# spec/02 EQ／スペクトル（12 件）

カタログ §2。共通規約（命名、ライセンス、バックエンド、決定論、共通テスト CT-1〜8）は `spec/01_dynamics.md` §0。特記の無い型は `stages: ["track","bus","master"]`、`master_slot: 1`。

カテゴリ全体の正典（最初に読む 1 本）：Välimäki & Reiss「All About Audio Equalization: Solutions and Frontiers」Applied Sciences 2016（オープンアクセスの総説）。

STFT 系 3 件（T02-03・04・06）の共通事項（BB-06）：

- 窓 `window` は e：1024／2048／4096（48 kHz 基準。sr に比例して拡大）、既定 2048。√Hann、75 % 重なり。レイテンシ＝窓長（宣言し、補償する）。`offline_only: False`、`allocates: True`
- 掛けるのは実数ゲイン（フレーム内ゼロ位相）。作用 0 の設定では STFT を通さず遅延だけにする（中立ヌル ≤ −120 dBFS を満たすため。通しても満たすことを別テストで確認）
- 共通パラメータ：`lo_hz`（f、20〜20000、既定 20）、`hi_hz`（f、20〜24000、既定 20000）、`mix`（f、0〜1、1）、`delta`（b、false：true で「取り除いた分」を出す）、`stereo_link`（b、true）。範囲の縁は 1/3 オクターブで作用を 0 へ落とす
- 共通テスト：(S1) 作用 0 でヌル ≤ −120 dBFS (S2) `delta` 出力＋通常出力＝遅延した入力（ヌル ≤ −120 dBFS） (S3) `lo_hz`〜`hi_hz` の外 1 オクターブの正弦の変化 ≤ 0.1 dB (S4) フレーム境界に同期した変調が出ない：定常正弦入力で出力包絡のリップル ≤ 0.05 dB
- 正典：Griffin & Lim「Signal Estimation from Modified Short-Time Fourier Transform」IEEE Trans. ASSP 1984（WOLA）／J. O. Smith『Spectral Audio Signal Processing』（オンライン公開の教科書。COLA、窓）／Cappé 1994（ゲインの時間平滑とミュージカルノイズ。IEEE Trans. SAP）

## T02-01 リニアフェイズ EQ

`linear_eq`｜A｜W1｜S｜Codex
既存 `eq` の `phase=linear`（1 バンド 1 FIR、小さなカット用）は変えない。本型は全バンドを 1 本の FIR にまとめる。

| id | 型 | 単位 | 範囲 | 既定 |
|---|---|---|---|---|
| `freq_hz` | a | Hz | 10〜24000、最大 16 個 | `[]` |
| `gain_db` | a | dB | −24〜24、`freq_hz` と同数 | `[]` |
| `bw_oct` | a | oct | 0.02〜6、同数 | `[]`（ピーク形だけ） |
| `low_shelf_hz` | f | Hz | 0〜2000 | 0（0＝無効） |
| `low_shelf_db` | f | dB | −24〜24 | 0 |
| `high_shelf_hz` | f | Hz | 0〜20000 | 0 |
| `high_shelf_db` | f | dB | −24〜24 | 0 |
| `hpf_hz` | f | Hz | 0〜2000 | 0 |
| `hpf_slope_db_oct` | e | dB/oct | 12／24／48 | 24 |
| `lpf_hz` | f | Hz | 0〜24000 | 0 |
| `lpf_slope_db_oct` | e | dB/oct | 12／24／48 | 24 |
| `resolution` | e | — | `low`／`mid`／`high`／`max` | `mid`（48 kHz で 2049／8193／32769／65537 タップ。sr に比例） |

- アルゴリズム：各バンドのアナログ原型の振幅応答（RBJ の形。双一次変換を通さないのでナイキスト付近が詰まらない）を dB で足す → 密な周波数格子（タップ数の 4 倍）で標本化 → 逆 FFT → カイザー窓 → 対称 FIR。FFT 畳み込み。プリリンギングの量（主ピーク前のエネルギー比と長さ）を記録に残す（SPEC §6.6.3）
- 正典：Oppenheim & Schafer『Discrete-Time Signal Processing』（FIR 設計、窓法）／Bristow-Johnson「Audio EQ Cookbook」／Välimäki & Reiss 2016
- テスト：(1) 全バンド 0 dB・フィルタ無効で、純遅延（ビット一致。畳み込みを通さない） (2) 係数が完全対称 (3) 目標振幅との誤差 ≤ 0.1 dB（`mid` 以上、100 Hz 以上、bw ≥ 0.3 oct）。それ未満の周波数・幅では実測誤差を記録に出す (4) CT-5（レイテンシ＝(taps−1)/2） (5) 1 バンドのとき既存 `eq`（linear）と振幅差 ≤ 0.2 dB
- 依存：BB-07

### 実装時の確定（統括の判断 D-9）

`linear_eq` は `implemented: false` を維持。100 Hz・0.3 oct・±24 dB・mid の誤差 ≤0.1 dBに未達であり、試験基準を変更していない。

## T02-02 ミッド／サイド EQ

**新しい型を作らない。チェーン項目の `channel` 欄（BB-04）＋既存 `eq`**｜A｜W1｜S｜Codex

- 書き方：`{"type":"eq","channel":"side","params":{…}}`。`channel`：`stereo`（省略時）／`mid`／`side`／`left`／`right`
- 許可する型：`gain`、`filter`、`eq`、`dynamic_eq`、`compressor`、`deesser`、`saturator`、`clipper`、および本プログラムの新型のうち各 spec が禁じないもの。不可：`pan`、`stereo`、`limiter`、`reverb`、`delay`、書き出し系、`aw.*`（native の写しを変えないため。W6 で再検討）
- エンジン：M＝(L+R)/2、S＝(L−R)/2 → 対象の 1 本をモノとして処理 → L＝M+S、R＝M−S。対象でない側には、処理のレイテンシと同じ遅延を入れる
- これで DESIGN_PHILOSOPHY §8 の「側成分だけへの動的処理」も `dynamic_eq`＋`channel: side` で書ける
- テスト：(1) `channel` 省略の全既存チェーンがバイト同一（G0-2） (2) `channel: side` の `eq` +6 dB：M のヌル ≤ −140 dBFS、S は +6 dB (3) `left`／`right`：反対チャンネルがビット一致 (4) レイテンシのある型（`eq` linear）で M と S の時間ずれ 0 (5) モノ入力に `stereo` 以外 → 拒否 (6) 不可の型に `channel` → 拒否
- 依存：BB-00、BB-04

## T02-03 ダイナミック共振抑制

`resonance_suppressor`｜B｜W3｜L｜**Opus 中**｜TV｜slot 2

STFT 共通パラメータ（既定 `lo_hz=200`、`hi_hz=16000`）に加えて：

| id | 型 | 単位 | 範囲 | 既定 |
|---|---|---|---|---|
| `depth_db` | f | dB | 0〜24 | 6（ビンごとの最大減衰。0＝作用なし） |
| `excess_db` | f | dB | 0〜24 | 6（包絡からこれだけ突き出た分から抑える） |
| `envelope_oct` | f | oct | 0.1〜2 | 0.5（包絡を作る平滑幅。広いほど多く拾う） |
| `notch_oct` | f | oct | 0.02〜0.5 | 0.1（減衰の周波数方向の広げ幅） |
| `attack_ms` | f | ms | 0〜200 | 5 |
| `release_ms` | f | ms | 5〜2000 | 80 |
| `tilt_db_oct` | f | dB/oct | −6〜6 | 0（高域ほど敏感に／鈍感に。1 kHz 軸） |

- アルゴリズム：(1) フレームごとのパワースペクトル (2) 対数周波数軸で一定オクターブ幅の平滑→スペクトル包絡（dB）(3) 突出＝ビン dB − 包絡 dB − `excess_db`（＋傾き補正）(4) 減衰＝clip(突出, 0, `depth_db`) (5) `notch_oct` 幅で最大値を取り、同幅で平滑（孤立ビンのゲイン孔を作らない）(6) ビンごとにフレームレートのアタック／リリース (7) 実数ゲインを掛けて合成
- 正典：Röbel & Rodet「Efficient Spectral Envelope Estimation and its Application to Pitch Shifting and Envelope Preservation」DAFx-05／Oppenheim & Schafer（ケプストラム）／Cappé 1994／Giannoulis ほか 2012（時定数）。**製品の内部は参照しない。上の公開手法の組み合わせとして再構成する**
- 調査レッグが先：包絡推定 3 案（対数軸の移動平均／ケプストラム・リフタ／true envelope）を比べて 1 つに決める
- テスト（STFT 共通 S1〜S4 に加えて）：(1) ピンクノイズ＋ 3 kHz に幅 0.05 oct・+12 dB の狭帯域成分：その周波数の減衰が min(`depth_db`, 12−`excess_db`) ±2 dB、1 オクターブ以上離れた 1/3 oct 帯の変化 ≤ 0.5 dB (2) ピンクノイズ単独：全 1/3 oct 帯の変化 ≤ 0.5 dB (3) 共振を 500 ms ごとに断続：減衰の立ち上がり・戻りが設定時定数 ±1 フレーム、無い区間の変化 ≤ 0.3 dB (4) 掃引正弦単独（包絡から最大に突出する入力）：減衰が `depth_db` を超えない (5) ゲインの時間変化の上限：フレーム間 Δ ≤ 時定数から導く理論値
- 依存：BB-06、BB-03

### 実装時の確定（統括の判断 D-13）

W3i の実測較正で `resonance_suppressor.excess_db` の既定を6→8 dBと確定した（範囲0〜24 dBは不変）。48 kHz・合成ピンク・seed12の最大変化は旧既定6で1.0012542718150919 dB、8で0.17592754983594874 dB、共振なし区間は0.08592044338814928 dB。許容値は変えず、値6を明示した入力も引き続き受け付ける。

## T02-04 スペクトル EQ（FFT ビン単位）

`spectral_dynamics`｜B｜W3｜M（T02-03 の後。同じ核）｜Codex｜TV｜slot 2

STFT 共通パラメータに加えて：

| id | 型 | 単位 | 範囲 | 既定 |
|---|---|---|---|---|
| `mode` | e | — | `compress`／`expand` | `compress` |
| `threshold_db` | f | dBFS | −100〜0 | −40（ビンのレベル。フルスケール正弦が 0 dBFS と読める正規化） |
| `threshold_tilt_db_oct` | f | dB/oct | −6〜6 | −3（1 kHz 軸。ピンク傾斜の素材に一様に効かせる） |
| `ratio` | f | :1 | 1〜20 | 3 |
| `knee_db` | f | dB | 0〜24 | 6 |
| `range_db` | f | dB | 0〜36 | 12 |
| `smooth_oct` | f | oct | 0〜1 | 0.1（検出の周波数平滑） |
| `attack_ms` | f | ms | 0〜200 | 10 |
| `release_ms` | f | ms | 5〜2000 | 100 |

- アルゴリズム：T02-03 の (3) を「絶対閾値（傾きつき）に対する静特性」に替えたもの。`expand` は閾値より下を下向き伸長
- テスト（S1〜S4 に加えて）：(1) 閾値より 12 dB 上の正弦：定常 GR が静特性 ±0.5 dB (2) 同時に鳴らした 1 オクターブ離れた閾値未満の正弦：変化 ≤ 0.2 dB (3) `ratio=1` でヌル ≤ −120 dBFS (4) 正規化：フルスケール正弦のビン読みが 0 ±0.2 dBFS（3 つの窓長で）
- 依存：BB-06、BB-03、T02-03 の核

## T02-05 ピッチ追従 EQ

`pitch_eq`｜B｜W3｜M｜Codex｜TV｜`offline_only: True`（音程の追跡が先読みを要する）

| id | 型 | 単位 | 範囲 | 既定 |
|---|---|---|---|---|
| `shape` | e | — | `peak`／`notch`／`low_shelf`／`high_shelf`／`hpf` | `peak` |
| `harmonic` | f | 倍 | 0.25〜32 | 1（基音の何倍に置くか） |
| `offset_semitones` | f | 半音 | −24〜24 | 0 |
| `gain_db` | f | dB | −24〜24 | 0 |
| `bw_oct` | f | oct | 0.02〜6 | 0.5 |
| `f0_min_hz` | f | Hz | 30〜1000 | 60 |
| `f0_max_hz` | f | Hz | 60〜4000 | 1000 |
| `confidence` | f | 0..1 | 0〜1 | 0.5（これ未満は無声扱い） |
| `unvoiced` | e | — | `hold`／`fallback`／`bypass` | `hold` |
| `fallback_hz` | f | Hz | 10〜24000 | 200 |
| `glide_ms` | f | ms | 0〜500 | 20 |
| `track` | c | x：秒／y：Hz 20〜8000 | 最大 65536 点 | `[]`（空＝自動追跡。書けば追跡せずこの線を使う） |

- アルゴリズム：(1) 基音：pYIN（`librosa.pyin`。フレーム・ホップ・分解能を固定）→ 中央値フィルタ → 無声区間の規則 → `glide_ms` の平滑 (2) 時変フィルタ：TPT 型 SVF（係数をサンプルごとに補間。中心は 0.45×sr で頭打ち）。`bypass` は無声区間でゲインを 0 dB へ 10 ms で寄せる
- **使った基音の線はレンダリング記録に残す**（librosa の版で追跡結果が動いても、何が効いたかを後から読めるように。再現が要るときは記録の線を `track` に書く）
- 正典：de Cheveigné & Kawahara「YIN, a fundamental frequency estimator for speech and music」JASA 2002／Mauch & Dixon「pYIN」ICASSP 2014／Zavalishin『The Art of VA Filter Design』（公開 PDF）。aubio（GPL）は使わない
- 決定論：librosa の版を固定。`track` を書いた描画は librosa に依存しない
- テスト：(1) 100→400 Hz を滑る正弦＋固定 3 kHz 正弦、`shape=notch, harmonic=1`：基音の残留 ≤ −20 dB（先頭 100 ms 以降）、3 kHz の変化 ≤ 0.2 dB (2) `track` 指定：フィルタ中心が線 ±1 % (3) 一定の基音：同じ周波数の静的フィルタとのヌル ≤ −80 dBFS (4) 係数更新による不連続なし（無音入力へ切り替えた直後の出力が単調減衰） (5) `gain_db=0`（`peak`）でビット一致 (6) 無声の 3 規則が宣言どおり
- 依存：BB-12、BB-05（線の評価）

## T02-06 自動スペクトルバランス

`spectral_balancer`｜B｜W3｜L｜**Opus 中**｜TV｜slot 3
**知覚モデルに基づく自前の近似であり、特定製品と同じ結果を主張しない。**

STFT 共通パラメータに加えて：

| id | 型 | 単位 | 範囲 | 既定 |
|---|---|---|---|---|
| `recover` | f | 0..1 | 0〜1 | 0.3（埋もれた帯域を持ち上げる強さ） |
| `tame` | f | 0..1 | 0〜1 | 0.3（周りを覆う帯域を抑える強さ） |
| `tilt_db_oct` | f | dB/oct | −3〜3 | 0（狙う釣り合いの傾き） |
| `max_change_db` | f | dB | 0〜12 | 6 |
| `time_ms` | f | ms | 20〜2000 | 150（ゲインの時間平滑） |
| `loudness_hold` | b | — | — | true（フレームごとの全体レベルを保つ） |

- アルゴリズム：(1) ERB 尺度の帯域へパワーを集約 (2) 広がり関数で励起パターンを作る (3) 帯域ごとに「自分の励起」対「他帯域から広がってくる励起」の比（信号対マスク比）(4) 比が低い帯域（埋もれ）を `recover` に比例して上げ、他を強く覆う帯域を `tame` に比例して下げる。`max_change_db` で切る (5) 帯域ゲインをビンへ滑らかに補間、`time_ms` で平滑、`loudness_hold` で全体を補正
- 正典：Glasberg & Moore「Derivation of auditory filter shapes from notched-noise data」Hearing Research 1990（ERB）／Moore, Glasberg & Baer「A Model for the Prediction of Thresholds, Loudness, and Partial Loudness」JAES 1997／Zwicker & Fastl『Psychoacoustics』／Painter & Spanias「Perceptual Coding of Digital Audio」Proc. IEEE 2000（マスキング・モデルの総覧）／Hafezi & Reiss「Autonomous Multitrack Equalization Based on Masking Reduction」JAES 2015／リポジトリ内の P-02 モデルと ISO 532-1 実装
- 調査レッグが先：(3)(4) の定式化を公開文献から確定する。P-02 のモデルを再利用できるかを確かめる（できれば観察量 `masking` と同じ物差しになる。**その場合「探す物差しと確かめる物差しが同じ」になる点を記録に明記する**。DESIGN_PHILOSOPHY §5.3）
- テスト（S1〜S4 に加えて）：(1) `recover=tame=0, tilt=0` でヌル ≤ −120 dBFS (2) ピンクノイズ：全 ERB 帯のゲイン ≤ ±0.5 dB (3) ピンク＋ 2 kHz の 1/3 oct 帯を +15 dB：`tame=1` でその帯が 2 dB 以上・`max_change_db` 以下で下がり、`tame` に対して単調 (4) 1 帯を −10 dB 凹ませた信号：`recover=1` でその帯が上がり、単調、上限内 (5) `loudness_hold=true` で積分ラウドネスの変化 ≤ 0.5 LU (6) フレーム間のゲイン変化が `time_ms` から導く上限以下
- 依存：BB-06、BB-15

## T02-07 AI アシスト EQ（提案系）

- 依存：BB-06、BB-15、T02-03 の統計

## T02-08 マッチ EQ

**下見コマンド `direction ref matcheq`（曲線を出す）＋プロセッサ `fir_eq`（曲線を当てる）**｜D＋A｜W4（`fir_eq` は W1）｜M｜Codex
Matchering（GPL）のコード・定数は使わない。

`fir_eq`：

| id | 型 | 単位 | 範囲 | 既定 |
|---|---|---|---|---|
| `curve` | c | x：Hz 10〜24000（対数補間）／y：dB −24〜24 | 最大 512 点 | `[]`（空＝素通し） |
| `amount` | f | 倍 | 0〜1.5 | 1（dB に掛ける） |
| `phase` | e | — | `linear`／`minimum` | `linear` |
| `resolution` | e | — | `low`／`mid`／`high`／`max` | `mid` |

`direction ref matcheq` の引数：`--target`（プロジェクトの段、または音声）、`--ref`（音声ファイル、または refstudy の ID）、`--smooth-oct`（1/12〜1、既定 1/3）、`--max-db`（1〜12、既定 6）、`--band-hz`（既定 30 18000）、`--section`、`--points`（8〜64、既定 32）。

- アルゴリズム：両者の長時間平均スペクトル（ウェルチ法。無音フレームを除く。積分ラウドネスを揃えてから）→ オクターブ幅平滑 → 差（dB）→ `--max-db` で切る → 帯域の外へ 1/2 oct で 0 に落とす → 点列に間引く。`fir_eq` は T02-01 と同じ設計器。`minimum` は実ケプストラムの折り返しで最小位相化
- 出力：曲線、両者のスペクトル、貼れる `chain_add`（`fir_eq`）。**リファレンスの音は保存しない**（測った値だけ。DESIGN_PHILOSOPHY §4.4）
- 正典：Welch 1967（IEEE Trans. Audio Electroacoust.）／J. O. Smith『Spectral Audio Signal Processing』（最小位相化）／Oppenheim & Schafer（ケプストラム）
- テスト：`fir_eq` (1) `curve=[]` でビット一致 (2) 曲線との振幅誤差 ≤ 0.2 dB（100 Hz 以上、`mid`） (3) `minimum`：振幅が `linear` と ±0.2 dB、レイテンシ 0、エネルギーの 99 % が先頭側。コマンド (4) ピンクノイズを既知の EQ に通したものをリファレンスにして、曲線が既知 EQ を ±1 dB で復元 (5) 出力を適用後、両者の 1/3 oct スペクトル差 ≤ 1 dB（切られていない帯域） (6) 読み取り専用、再現一致
- 依存：BB-00（curve）、BB-07

## T02-09 ターゲット型ローエンド EQ

**下見コマンド `direction suggest lowend`**｜D｜W4｜S（T02-07・08 の後）｜Codex

- 引数：`--project`／`--target`（既定 `master` 相当のミックス）、`--refsheet`／`--ref-kb`（**必須**。同梱の「ジャンル目標」は持たない。目標は自分で測ったリファレンスの分布）、`--max-db`（1〜6、既定 3）、`--section`
- アルゴリズム：20〜320 Hz を 1/2 オクターブ 8 帯に分け、各帯のレベルを 300 Hz〜3 kHz の基準レベルとの差で表す。リファレンス集合の四分位範囲の内側なら「提案なし」。外側なら、範囲の縁までの差を `--max-db` で切って提案
- 出力：帯ごとの現在値・リファレンスの中央値と範囲・提案（最大 4 バンドの `eq`）・当てになり度（リファレンス 3 曲未満は `low`）。DESIGN_PHILOSOPHY §2 の注意（低音は音符ごとに変わる。見るべきは最低音の動き）を出力の注記に固定で付ける
- テスト：範囲内の素材で提案 0 件／帯を ±6 dB ずらした素材で向きと量が合う／読み取り専用／リファレンス無しは明示エラー／再現一致
- 依存：T02-08 のスペクトル測定

## T02-10 ビンテージ EQ モデリング

4 つの型（方式名で呼ぶ）｜A｜W2｜M（S×4）｜Codex。共通：`drive_db`（f、0〜12、0＝飽和段を通さない。既存 `saturator` の tanh を後段に）、`output_db`（f、−24〜12、0）。

| 型 | 方式 | パラメータ（型・範囲・既定） |
|---|---|---|
| `passive_eq` | 受動 LC 回路のプログラム EQ。低域の持ち上げと減衰を同時に使うと棚の上に谷ができる | `low_freq_hz` e 20／30／60／100（60）、`low_boost_db` f 0〜14（0）、`low_atten_db` f 0〜18（0）、`high_freq_hz` e 3000／4000／5000／8000／10000／12000／16000（8000）、`high_boost_db` f 0〜18（0）、`high_bw` f 0〜1（0.5。0＝鋭い）、`high_atten_freq_hz` e 5000／10000／20000（10000）、`high_atten_db` f 0〜16（0） |
| `inductor_eq` | インダクタ式の卓 EQ。固定周波数の段切り替え | `hpf_hz` e 0／50／80／160／300（0）、`low_freq_hz` e 35／60／110／220（110）、`low_db` f −16〜16（0）、`mid_freq_hz` e 360／700／1600／3200／4800／7200（1600）、`mid_db` f −18〜18（0）、`high_db` f −16〜16（0。12 kHz 固定の棚） |
| `proportional_eq` | 比例 Q。量が大きいほど幅が狭くなる | `freq_hz` f 30〜20000（1000）、`gain_db` f −12〜12（0）、`shape` e `peak`／`low_shelf`／`high_shelf`（`peak`）、`bw_min_oct` f 0.3〜2（0.6：最大ゲイン時の幅）、`bw_max_oct` f 1〜4（2.5：0 dB 近傍の幅） |
| `baxandall_eq` | 緩い棚 2 本のトーン回路 | `bass_hz` e 74／84／130／166／230／361（84）、`bass_db` f −5〜5（0）、`treble_hz` e 1600／2100／3400／4800／7100／18000（7100）、`treble_db` f −5〜5（0） |

- アルゴリズム：公開されている回路図・取扱説明書の特性図から、節点解析で伝達関数 H(s) を導く → 2 倍オーバーサンプルの双一次変換（プリワープ）で SOS へ。飽和は EQ の後段。**市販プラグインの出力を測って合わせ込まない**（§0.2）。周波数の段の値は方式の典型値で、調査レッグが公開資料で確かめて確定する（上表は仮）
- 正典：Baxandall「Negative-Feedback Tone Control」Wireless World 1952／各機種の公開回路図と取扱説明書（特許は失効済みのものだけを読む。調査レッグが失効を確かめる）／Yeh & Smith の節点解析による回路離散化の論文群（DAFx）／Orfanidis「Digital Parametric Equalizer Design with Prescribed Nyquist-Frequency Gain」JAES 1997／Välimäki & Reiss 2016
- テスト：(1) 解析的 |H(jω)| との誤差 ≤ 0.2 dB（20 Hz〜20 kHz） (2) 全量 0 でビット一致 (3) `passive_eq`：低域の持ち上げと減衰を同量で同時に掛けると、角周波数の 2〜10 倍に谷が出る（谷の存在と位置を検査） (4) `proportional_eq`：|gain| に対して −3 dB 幅が単調に狭まる (5) `baxandall_eq`：傾き ≤ 6 dB/oct (6) `drive_db=0` で飽和段を通らない（線形性：入力 −20 dB でも応答同一）
- 依存：BB-13（飽和・オーバーサンプル）
- 弱点：できるのは「その方式の特性」で、「その機種の音」ではない（トランス・真空管段の非線形は tanh で代用）

### 実装時の確定（統括の判断 D-13）

C6a で `passive_eq`・`inductor_eq`・`proportional_eq` の内部倍率を2→32へ変更し、物理周波数での誤差を測定した。公開パラメータの ID・範囲・既定は不変。固定輸送遅延352入力サンプルを内部補償し、中立では再標本化も迂回する。`proportional_eq` は `bw_min_oct <= bw_max_oct` を要求する（W2a2）。特定回路との同等性は主張しない。

## T02-11 チルト EQ

`tilt_eq`｜A｜W1｜S｜Codex

| id | 型 | 単位 | 範囲 | 既定 |
|---|---|---|---|---|
| `pivot_hz` | f | Hz | 100〜10000 | 650 |
| `tilt_db` | f | dB | −6〜6 | 0（高域端のゲイン。低域端は逆符号で同量） |
| `phase` | e | — | `minimum`／`linear` | `minimum` |

- アルゴリズム：1 次の傾斜フィルタ（軸で 0 dB、両端で ±`tilt_db` に漸近、単調）。`linear` は同じ振幅を BB-07 で FIR 化
- テスト：軸で 0 ±0.05 dB／20 Hz と 20 kHz で ∓・± `tilt_db` に対し ±0.5 dB（軸 650 Hz）／全域で単調／傾き ≤ 6 dB/oct／`tilt_db=0` でビット一致／`linear` は T02-01 の (2)(4)
- 依存：BB-07（`linear` のみ）

## T02-12 カット専用フィルタ集（ブリックウォール）

`cut_filter`｜A｜W1｜S｜Codex。既存 `filter` は変えない。

| id | 型 | 単位 | 範囲 | 既定 |
|---|---|---|---|---|
| `kind` | e | — | `hpf`／`lpf` | `hpf` |
| `freq_hz` | f | Hz | 10〜24000 | 30 |
| `family` | e | — | `butterworth`／`linkwitz_riley`／`bessel`／`elliptic` | `butterworth` |
| `slope_db_oct` | e | dB/oct | 6／12／18／24／36／48／72／96 | 24（次数＝値/6。`linkwitz_riley` は 12 の倍数だけ。`elliptic` は次数の指定として読む） |
| `resonance_db` | f | dB | 0〜12 | 0（カットオフのピーク。`butterworth` の 12 dB/oct 以上だけ） |
| `ripple_db` | f | dB | 0.01〜1 | 0.1（`elliptic` の通過域） |
| `stopband_db` | f | dB | 40〜120 | 80（`elliptic` の阻止域） |
| `phase` | e | — | `minimum`／`linear` | `minimum` |

- アルゴリズム：SOS（2 次区間の縦続、float64）。設計は scipy.signal（BSD）を使ってよい。`resonance_db` は最も Q の高い区間の Q を調整。`linear` は振幅を BB-07 で FIR 化（往復フィルタにしない：振幅が 2 乗になるため）
- 交差検査：`family` と `slope_db_oct`・`resonance_db` の組み合わせ、`freq_hz` < 0.98×ナイキスト
- 正典：Oppenheim & Schafer／Parks & Burrus『Digital Filter Design』／Linkwitz 1976
- テスト：(1) `butterworth`：−3 dB 点が `freq_hz`（±1 %）、傾き ±1 dB/oct (2) `elliptic`：阻止域 ≥ `stopband_db`、通過域リップル ≤ `ripple_db` (3) `resonance_db`：ピーク ±0.5 dB (4) 数値安定：96 kHz・20 Hz・96 dB/oct でインパルス応答が有限で減衰 (5) 既存 `filter` と共通の設定でヌル ≤ −120 dBFS (6) `linkwitz_riley` の HPF＋LPF の和が全通過（振幅 ±0.01 dB）
- 依存：BB-07（`linear` のみ）
