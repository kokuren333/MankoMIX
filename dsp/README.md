# dsp — DSP エンジン

抽象プロセッサのグラフ（JSON）を受け取り、バックエンドに割り当てて決定的に実行する（`docs/SPEC.md` §3.2、§6.5.2）。

バックエンド:

- `ffmpeg` — ユーザー環境の FFmpeg を外部プロセスとして呼ぶ。LGPL 構成に限る。コードは取り込まない
- `native` — 自前のネイティブ DSP 核。MIT / Apache-2.0 のコードだけで構成する。将来のプラグイン核
- `reference` — 数値計算ライブラリ上の参照実装

守ること:

- ネイティブ核は、UI、ファイル入出力、ネットワーク、エージェント層、プラグイン SDK のヘッダに依存しない（§14.2）
- GPL / AGPL のコードを持ち込まない（§13）

現在は骨格のみ。実装は次フェーズ。
